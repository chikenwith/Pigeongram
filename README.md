  Инструкция по настройке и использованию PIGEONGRAM v5.3 OMNI-RELAYPIGEONGRAM — это закрытое программное решение для создания защищенных и отказоустойчивых каналов связи внутри частных виртуальных сетей. Программа предназначена для безопасного обмена данными и файлами между удаленными рабочими станциями.⚙️

  ⚙️Шаг 1. Сетевая интеграция через Radmin VPNДля обхода ограничений брандмауэров (Firewall) и NAT программа оптимизирована для работы в связке с Radmin VPN.Скачайте программу: Загрузите бесплатный клиент с официального сайта radmin-vpn.com.Создайте сеть: Откройте Radmin VPN на хост-машине (сервере), нажмите «Создать сеть», задайте имя и пароль.Подключите участников: На удаленных компьютерах (клиентах) нажмите «Присоединиться к сети» и введите те же данные.Зафиксируйте IP: Каждый компьютер в сети получит внутренний IP-адрес формата 26.x.x.x.📥 

  ⚙️Шаг 2. Установка и запуск PIGEONGRAMПрограмма поставляется в виде готовых скомпилированных бинарных файлов и не требует сложной установки.На хост-машине (сервере):Запустите pigeongram.exe.Выполните привязку (Binding) сервера к вашему внутреннему IP-адресу из Radmin VPN (26.x.x.x). Это изолирует трафик внутри приватного туннеля.На удаленных машинах (клиентах):Запустите pigeongram.exe.Для подключения введите IP-адрес хост-машины (формата 26.x.x.x), отображаемый в Radmin VPN. 📂 Работа с файлами и важные особенностиОтправка файлов: Осуществляется с хост-машины с помощью текстовой команды: /file путь_до_файла (например: /file C:\docs\report.txt).

  ⚠️ ОСТОРОЖНО (Автоматический прием): На удаленных машинах файлы принимаются без подтверждения.Хранение данных: Все скачанные файлы автоматически сохраняются в папку downloads, которая создается в той же директории, где находится pigeongram.exe.Самоуничтожение: В программе доступна функция экстренного самоуничтожения ПО.

  🔒 Безопасность и технологииШифрование X25519: Сквозное шифрование (E2EE) на эллиптических кривых полностью исключает возможность перехвата данных в сети.Изоляция Omni-Relay: Архитектура гарантирует, что сервер является лишь транзитным узлом. Он физически не имеет доступа к ключам шифрования пользователей и не может прочесть переписку.Высокая стабильность: Поддержка множества одновременных сессий без потери скорости передачи данных.
