🕊️ PIGEONGRAM v5.3 OMNI-RELAY
PIGEONGRAM — закрытое программное решение для организации отказоустойчивых и защищенных каналов связи внутри частных виртуальных сетей. Предназначено для безопасного обмена данными между удаленными рабочими станциями.

🌐 Сетевая интеграция: Radmin VPN
Для обеспечения стабильной связи через интернет и обхода ограничений NAT/Firewall, программа оптимизирована для работы в связке с Radmin VPN.
Скачать Radmin VPN: Официальный сайт
Инструкция: Создайте виртуальную сеть в Radmin VPN, получите внутренний IP-адрес (формата 26.x.x.x) и используйте его для привязки (Binding) сервера PIGEONGRAM. Это гарантирует, что ваш трафик будет изолирован внутри приватного туннеля.

🔒 Безопасность и технологии
Proprietary Encryption Engine: Использование криптографии на эллиптических кривых (X25519) для исключения возможности перехвата данных (E2EE).
Relay Isolation: Архитектура "Omni-Relay" гарантирует, что сервер является лишь транзитным узлом и не имеет доступа к ключам шифрования пользователей.
Multi-User Stability: Поддержка множественных одновременных сессий без потери скорости передачи.

📥 Установка и запуск
1 Программа поставляется в виде скомпилированных бинарных файлов (или закрытого дистрибутива).

2 Установите Radmin VPN и создайте общую сеть.

3 Запустите pigeongram.exe на хост-машине.

4 Запустите pigeongram.exe на удаленных машинах для подключения  используя IP Address хост машины Radmin VPN.
